# Drizzle

A responsive React restaurant concept inspired by the supplied reference. Built with Vite, GSAP ScrollTrigger, and Lucide icons.

## Run

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Menu categories are interactive. The reservation dialog and newsletter are frontend demonstrations; no bookings or emails are sent. Photography is served from Unsplash and fonts from Google Fonts, requiring an internet connection.
